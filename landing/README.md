# Spacewars landing
Static landing at the existing game origin. Links are enabled only by a validated native download catalog; no invented installer URLs. `gameplay.png` is the current Unity prototype screenshot from consolidation final-manual-player/native-01.png. `hero.png` is generated concept art, explicitly captioned as illustration.

`sw.js` retires the former browser offline worker on its next update. It claims clients, unregisters, and leaves caches and open matches untouched. Subsequent navigation uses the native landing.
